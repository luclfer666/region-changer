# Region Changer

Region Changer — это DLL-модуль и Injector для Deadlock, который позволяет выбрать регион и сервер подключения через внутриигровое меню.

## Возможности

- выбор региона и сервера из доступного списка;
- включение и отключение Region Changer отдельным переключателем;
- русская и английская локализация меню;
- смена акцентного цвета интерфейса через color picker;
- открытие меню клавишами `Insert` и `Delete`;
- плавная анимация открытия и закрытия меню;
- звуковые эффекты для открытия, закрытия, кнопок и переключателя;
- автоматическое открытие меню при входе в матч;
- проверка доступности новой версии при запуске Injector;
- переход на страницу релиза GitHub при подтверждении обновления;
- автоматический запуск Deadlock через Steam, если игра ещё не запущена;
- ожидание свежего процесса игры перед инжектом;
- загрузка `dysonbehind.dll` в процесс Deadlock.

## Структура релиза

```text
release/
├── Injector.exe
└── dysonbehind.dll
```

`Injector.exe` должен находиться рядом с `dysonbehind.dll`.

## Запуск

1. Скачайте актуальный архив релиза.
2. Распакуйте `Injector.exe` и `dysonbehind.dll` в одну папку.
3. Запустите `Injector.exe` от имени администратора.
4. Injector проверит наличие обновления.
5. Если доступна новая версия, выберите:

```text
1 — открыть страницу обновления
2 — продолжить запуск текущей версии
```

6. После проверки Injector дождётся запуска Deadlock и выполнит загрузку DLL.
7. В игре откройте меню клавишей `Insert` или `Delete`.

## Управление

| Клавиша | Действие |
|---|---|
| `Insert` | открыть или закрыть меню |
| `Delete` | открыть или закрыть меню |
| `Левая кнопка мыши` | взаимодействие с меню |

При открытии меню управление мышью передаётся интерфейсу. При закрытии управление возвращается игре.

## Обновления

Текущая версия задаётся в `src/injector.cpp`:

```cpp
static constexpr const char* CURRENT_VERSION = "1.0.2";
```

Для нового релиза:

1. измените `CURRENT_VERSION` на новую версию;
2. соберите `Injector.exe` и `dysonbehind.dll`;
3. создайте GitHub Release с соответствующим тегом, например `1.0.3`;
4. прикрепите к релизу собранные файлы или архив.

Injector проверяет GitHub Releases API репозитория:

```text
https://github.com/wrongsprat/region-changer/releases
```

При наличии более новой версии Injector предлагает открыть страницу релиза. Файлы автоматически не скачиваются и не заменяются.

## Сборка

Требования:

- Windows 10 или Windows 11;
- Visual Studio с MSVC и Windows SDK;
- CMake 3.20 или новее;
- DirectX 11;
- Steam и установленный Deadlock.

Сборка Release:

```text
cmake --build build --target Injector --config Release
```

После сборки файлы автоматически копируются в каталог `release/`.

## Звуки и ресурсы

Интерфейс использует встроенные ресурсы:

- звук выбора кнопок;
- звук включения переключателя;
- звук выключения переключателя;
- звук открытия меню;
- звук закрытия меню;
- шрифты и иконки.

Ресурсы хранятся внутри проекта и не требуют отдельных файлов рядом с DLL.

## Логи

Injector создаёт:

```text
injector_debug.txt
```

DLL создаёт собственный лог:

```text
dysonbehind_debug.txt
```

Логи помогают проверить запуск, проверку версии, поиск процесса Deadlock и результат инжекта.

## Важные замечания

- Injector и DLL должны соответствовать одной версии.
- Не переименовывайте `dysonbehind.dll`, если не передаёте Injector путь к DLL вручную.
- Для проверки обновлений требуется доступ к GitHub.
- Если GitHub недоступен, Injector продолжит обычный запуск текущей версии.
- Автоматической замены файлов при обновлении нет: Injector только предлагает открыть страницу релиза.
